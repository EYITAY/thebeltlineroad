# The Belt Line Road

**Every honest answer runs straight. An incentive pulls it off its line.**

Inspired by **Belt Line Road in Dallas, TX**, The Belt Line Road is an interactive AI safety visualization exploring how incentives can influence the behavior and outputs of large language models (LLMs).

Belt Line Road connects communities across Dallas County through an extensive network of roads. That idea of connection provides the conceptual starting point for this project: different paths, pressures, and points of intersection can shape the journey.

In The Belt Line, those paths become representations of model responses. Incentives act as forces that can pull an otherwise straight trajectory away from its intended direction.

The project explores a central question in AI safety:

*What happens when an AI system has an incentive to give an answer other than the most honest one?*

By translating incentive pressures into an interactive visual experience, The Belt Line makes an abstract AI alignment problem easier to explore, discuss, and investigate.
